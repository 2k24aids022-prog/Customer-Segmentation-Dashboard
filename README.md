# Customer Segmentation Dashboard

## 📊 Project Overview

The Customer Segmentation Dashboard is a Power BI project that analyzes customer data to identify distinct customer groups based on demographics, income, and spending behavior. The dashboard provides interactive visualizations that help businesses understand customer patterns, improve targeting strategies, and make data-driven decisions.

## 🎯 Objectives

* Segment customers based on purchasing behavior and spending patterns.
* Identify high-value and low-value customer groups.
* Analyze customer demographics and income distribution.
* Support strategic marketing and customer retention initiatives.

## 🛠️ Tools & Technologies

* Power BI
* Microsoft Excel / CSV Dataset
* Power Query
* DAX (Data Analysis Expressions)

## 📈 Dashboard Features

* Customer Segmentation Analysis
* Spending Score Distribution
* Income vs Spending Analysis
* Demographic Insights
* Interactive Filters and Slicers
* KPI Cards and Summary Metrics
* Customer Group Comparison

## 🔍 Key Insights

* Identified distinct customer segments based on spending habits and income levels.
* High-income customers do not always have the highest spending scores.
* Certain customer groups contribute significantly to overall business value.
* Customer behavior patterns can be used for personalized marketing campaigns.
* Segmentation helps improve customer engagement and retention strategies.
